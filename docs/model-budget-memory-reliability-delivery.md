## 当前规则

- 用户主动对话不设应用侧每日次数/Token 配额。必要状态更新、工具续接、召回查询向量、回复自动语音与手动重播沿用同一个前台来源。记录用量，但不因旧 200/300 次上限停止。
- 来源由后端可信的轮次上下文传递；客户端不能通过用途名或 JSON 中的来源字段把后台工作变成前台。线程池检索和异步语音保留来源；后台整理与向量工作者主动进入后台上下文。
- 后台预算独立计量，默认模型 150 次、向量 200 次、语音 200 次/上海现实日；记忆编码另有每日 50 次子上限，后台每种请求每分钟最多 12 次。已有升级前后台记录按已知用途纳入，保留所有旧用量，不清零绕过保护。
- 旧 `EMBER_DAILY_CHAT_LIMIT` 仅作为未显式设置后台上限时的迁移基数，旧当日总额度覆盖不再拦截用户，也不追加后台预算。时间加速与读档不能恢复现实调用预算。
- 供应商余额、限流及连接故障仍然有效；“应用不限额”不等于供应商免费或一定可达。界面明确区分前台不限额、后台用量、失败和用量未知。

## 整理与恢复

编码在独立的单工作者中运行，模型网络请求不持有世界操作锁。领取、来源快照和结果提交仍受锁保护；新用户输入到达后不再启动下一片整理。存读档等待编码检查点落盘，再处理世界切换；旧代次返回结果不能提交。

按来源行领取较小日志前缀，保守估算输入预算，保留提示词与输出空间。超长消息拆成带原 ID、片段位置的编码输入；原始整行直到所有片段入库后才确认消费。上下文超限或重复超时时可缩小当前片段，已完成片段不重编码。暂停在当前请求结束后停止启动剩余编码片段及排队向量任务，保留待办；继续后从检查点恢复。

阶段检查点保存在 `working_memory.json` 与失败向量待办中：编码片段 → 已校验记忆 → 正文/洞察向量 → 数据库提交回执 → 来源确认。相同正文与洞察复用向量；数据库失败不重新生成已保存向量。存档前核对每份待办完整进入工作记忆，不能只存 ID 而丢失内容。

失败分类包括预算等待、供应商限流、连接、超时、认证、配置、上下文、结果/引用、向量和数据库。可恢复失败指数退避并加入少量随机间隔，每片/阶段最多 3 次自动尝试；结果格式最多 2 次。认证、配置和来源变化直接要求处理。预算等待不增加失败次数。

常驻服务对同一后台模型配置连续 3 次外部失败后暂停通道 15 分钟，到期只放行一个探测；认证/配置失败等待配置改变。状态跨重启保留。用户对话不受后台熔断影响。HTTP 层仅在发送请求正文前有限重试 TCP/TLS 建连，SDK 的隐式请求重试关闭；记忆编码另有整次截止时间，晚到结果不写世界。

这次网络抽查同时发现：模型域名的部分解析地址 TLS 握手成功、部分超时。连接重试用于减轻此类节点故障，不能保证上游一直正常；向量接口连通性与聊天接口要分开检查。

## 使用

仍双击 `start_service.bat` 启动，更新代码后再次运行会构建并更新服务；停止使用 `stop_service.bat`，不删除卷。服务实际配置在私有 `deploy/service.env`。

```dotenv
EMBER_BACKGROUND_CHAT_LIMIT=150
EMBER_BACKGROUND_EMBEDDING_LIMIT=200
EMBER_BACKGROUND_TTS_LIMIT=200
EMBER_MEMORY_DAILY_LIMIT=50
EMBER_BACKGROUND_PER_MINUTE=12
EMBER_MEMORY_INPUT_BUDGET=16000
EMBER_MEMORY_OUTPUT_TOKENS=2048
EMBER_MEMORY_REQUEST_TIMEOUT=60
```

输入预算是保守估算，不冒充供应商计费 Token。修改配置后重建/重启服务；不需要为了“用户不限额”再设置一个极大总额度。

“设置 → 连接与服务 → 后台调用限额”可分别调整模型、向量、语音和记忆整理的每日上限，以及每种调用的每分钟上限。填 0 会暂停对应调用，也可以逐项选择「不限额」或点击「解除全部后台限额」。设置保存在服务数据库，保存后立即应用，重启和读档后继续生效。环境变量提供尚未在页面设置的默认值。供应商仍按自己的额度和限流规则处理请求。

“设置 → 服务状态”显示编码、向量和提交阶段、最近成功、退避时间及错误类别，并可暂停、继续或重试指定批次。限额变更后，处于预算等待的任务会在下次调度时重新检查。后台重试继续按后台调用处理。

新发生的用户回复失败会显示“重试回复”：沿用用户消息 ID，新建回复轮次，只允许重试当前失败轮次，重复点击或旧请求重放不会重复执行。原用户消息和已确认的状态不重复写入/更新；实际失败于准备状态时仍会重新准备。

`diagnose.bat` 继续只读检查，后台预算耗尽显示为后台等待，不能把它报告成用户每日聊天额度耗尽。测试环境可显式设置 `EMBER_TTS_ENABLED=false` 禁止调用真实语音供应商；这与语音每日配额独立，正常服务默认开启。
